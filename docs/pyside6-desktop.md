# PySide6 Desktop

Отдельная нативная оболочка, не заменяющая CLI, Web UI или экспериментальную Tkinter-ветку.

## Запуск

```bash
python -m pip install -e '.[desktop,images]'
python -m interfaces.pyside6.app
```

На Ubuntu для запуска Qt может понадобиться системная библиотека `libxcb-cursor0`. Используются системная тема и нейтральные цвета, без web-сервера.

## Интерфейс

- **Скачать:** ссылка или drag-and-drop ссылки RanobeLib, название и обложка книги, перевод, все/первые 10/последние 10/диапазон по ID, EPUB/TXT/HTML.
- **Очередь:** задания выполняются последовательно в фоновых потоках, процесс загрузки не блокирует окно.
- **История:** название, формат, локальная дата, размер; двойной клик открывает файл.
- **Настройки:** общая папка сохранения (по умолчанию системный Downloads), очистка постоянного кеша, Bearer-токен RanobeLib, версия и ссылка на https://github.com/SayatYuss, диагностический журнал.

При авторизации токен проверяется через `/auth/me` и сохраняется в системном keyring; в интерфейсе сверху справа показывается `username` после проверки. Токен в конфигурационные JSON и логи не пишется.

Закрытие окна сворачивает приложение в системный трей, если он доступен. Загрузки продолжаются, после завершения показывается уведомление через трей. Если трей не поддерживается, окно закрывается обычным способом. Во время активной загрузки приложение блокирует штатный выход.

Кеш, история и настройки сохраняются в системном каталоге данных пользователя через Qt `QStandardPaths`. Файлы скачиваются в указанную папку, при конфликте имён создаётся новое имя.

## Тестирование до релиза

Открой Actions → **PySide6 desktop** → успешный запуск ветки `feature/pyside6-desktop` → **Artifacts**. Скачай `pyside6-windows`, `pyside6-macos` или `pyside6-linux`. Публикация GitHub Release не требуется.

Сборки не подписаны: Windows SmartScreen и macOS Gatekeeper могут предупреждать о неизвестном издателе. Linux AppImage может требовать FUSE. Текущее тестирование проверяет упаковку и импорт; скачивание реальной книги, трей, системный keyring и отображение обложек нужно проверить вручную на целевой ОС.
