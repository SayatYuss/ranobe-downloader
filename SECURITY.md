# Security Policy

## Сообщение об уязвимости

**Не публикуй рабочие токены, ключи, приватные данные или шаги эксплуатации в публичных issues.** Свяжись с владельцем репозитория через приватный канал GitHub (если для репозитория включён механизм приватного сообщения об уязвимости) либо другой приватный контакт, указанный владельцем. Не создавай публичный issue с секретами.

## Поддерживаемые версии

Проект находится на ранней стадии разработки; гарантированных сроков исправления и поддержки веток пока нет.

## Рекомендации по развёртыванию

- HTTP API по умолчанию используй только на `127.0.0.1`. Для внешнего доступа требуются отдельная аутентификация, HTTPS и ограничения запросов.
- Ограничь `TELEGRAM_ALLOWED_USER_IDS` в личном боте.
- Никогда не передавай токены в URL, логах и issue; при утечке немедленно перевыпускай.
- Не сохраняй загруженные книги и секреты в git.
- Не рассчитывай на разграничение пользователей в HTTP API: оно пока отсутствует.
