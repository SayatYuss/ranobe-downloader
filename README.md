# Ranobe Downloader

Ranobe Downloader сохраняет произведения с **RanobeLib** и **MangaLib** в файлы EPUB, TXT и HTML для чтения вне сайта. Можно скачать всю книгу или выбранные главы и выбрать перевод, если их несколько.

**Для обычного использования скачайте приложение для своей ОС из [Releases](https://github.com/SayatYuss/ranobe-downloader/releases). Python и Node.js устанавливать не нужно.**

| Формат | Для чего подходит |
| --- | --- |
| EPUB | Электронные книги и приложения-читалки; оглавление и изображения |
| TXT | Простой текст без изображений |
| HTML | Чтение в браузере; изображения включаются в файл |

## Первый запуск

1. Откройте [Releases](https://github.com/SayatYuss/ranobe-downloader/releases) и выберите выпуск.
2. В разделе **Assets** скачайте файл для своей системы.
3. Запустите приложение и вставьте HTTPS-ссылку на страницу произведения RanobeLib.
4. Нажмите **Найти**, выберите перевод, главы и формат.
5. Нажмите **В очередь**. Готовая книга появится в папке загрузок; открыть её можно из вкладки **История**.

| Система | Файл |
| --- | --- |
| Windows x64 | `RanobeDownloader-Windows-x64.exe` |
| macOS | `RanobeDownloader-macOS.dmg` |
| Linux x86_64 | `RanobeDownloader-Linux-x86_64.AppImage` |

Файлы `.whl`, исходный архив и архив Web UI предназначены для запуска из исходников или интеграции. Для настольного приложения они не нужны. Сборки Windows и macOS не имеют подписи издателя. Инструкции запуска, архитектура macOS и возможные проблемы описаны в [руководстве приложения](docs/desktop.md).

## Возможности приложения

- Выбор перевода, всей книги, первых/последних 10 глав или своего диапазона.
- Обложки и перетаскивание ссылки в окно.
- Последовательная очередь, отмена загрузки и удаление ожидающих заданий.
- История с поиском, открытием файла/папки и повторным скачиванием.
- Сохраняемые настройки и кеш, общая папка загрузок, системная/светлая/тёмная тема.
- Авторизация по токену собственной учётной записи, системный трей и уведомления.

Трей и уведомления зависят от рабочего окружения. Очередь не восстанавливается после перезапуска, а история и кеш сохраняются.

## Скачать с телефона через Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/SayatYuss/ranobe-downloader/blob/develop/notebooks/ranobe_downloader_colab.ipynb)

Без установки Python на телефон и без собственного сервера: откройте notebook, подключите CPU-среду и выполните шаги установки, выбора книги, перевода и глав. Готовый EPUB/TXT/HTML скачивается через браузер. Среда временная; сохраните результат до отключения.

[Пошаговая инструкция](docs/google-colab.md). Если репозиторий приватный, загрузите notebook вручную в Colab и выберите установку из wheel.

## Другие способы использования

Все интерфейсы используют общее ядро. Запускать их одновременно не требуется.

| Способ | Кому подходит | Руководство |
| --- | --- | --- |
| Настольное приложение | Скачать книгу без терминала | [Desktop](docs/desktop.md) |
| CLI | Команды, скрипты и пакетные сценарии | [Командная строка](docs/cli-chapter-range.md) |
| Python-библиотека | Использовать загрузчик в своей программе | [Python API](docs/python-api.md) |
| Web UI + HTTP API | Работать в браузере с локальным сервером | [Web UI](docs/web-ui.md) |
| HTTP API | Подключить собственный клиент к серверу | [HTTP API](docs/http-api.md) |
| Telegram-бот | Развернуть собственного бота | [Telegram](docs/telegram-ui.md) |

Для перечисленных ниже локальных интерфейсов сначала выполните [установку из исходников](docs/installation.md). Проект требует Python 3.10+; Web UI дополнительно требует Node.js и npm. Пример CLI после установки:

```bash
ranobe --help
ranobe download "ССЫЛКА_НА_ПРОИЗВЕДЕНИЕ" --limit 10 --format epub --resume
```

Замените текст в кавычках ссылкой со страницы произведения. Поддерживаются ссылки RanobeLib и MangaLib. Если переводов несколько, CLI предложит выбрать один. Подробности: [MangaLib](docs/mangalib.md).

## Авторизация и ограничения

Для доступных публичных произведений токен может не понадобиться. Если требуется вход, приложение и CLI принимают Bearer-токен собственной учётной записи. Подробнее: [авторизация](docs/authentication.md).

- Поддерживаются RanobeLib и MangaLib через CLI и Python API. Desktop/Web UI/Telegram пока используют только RanobeLib. Изменения сайтов могут нарушить совместимость.
- Недоступные платные главы пропускаются, поэтому файл может быть неполным. Загрузчик не обходит ограничения доступа.
- HTTP API не имеет встроенной авторизации и изоляции пользователей. По умолчанию используйте его только локально.
- API проекта экспериментальные: совместимость между версиями не гарантируется.

Используйте проект для материалов, которые вы вправе сохранять, с соблюдением правил источника.
