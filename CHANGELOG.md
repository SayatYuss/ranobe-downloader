# История изменений

Изменения сгруппированы по выпускам. Установка и использование: [README](README.md), все руководства: [docs](docs/README.md).

## [0.4.2] - 2026-11-13

### Fixed
- Fixed Windows atomic file export failure.
- Fixed EPUB and TXT export errors caused by invalid file descriptors.

## [0.4.1] — 2026-11-1

### Добавлено

- Публикация Python-пакета в PyPI через GitHub Actions Trusted Publishing после успешной сборки всех интерфейсов.
- Метаданные лицензии MIT и ссылки на репозиторий, документацию и сообщения об ошибках.
- Google Colab Notebook для скачивания EPUB/TXT/HTML через браузер без локальной установки Python.

### Улучшено

- Руководства для новых пользователей и инструменты сборки Web UI/GitHub Actions.

## [0.4.0] — 2026-11-01

### Добавлено

- Настольное приложение на PySide6 с вкладками «Скачать», «Очередь», «История» и «Настройки».
- Системная, светлая и тёмная темы с нейтральным серым оформлением.
- Обложки произведений, перетаскивание ссылок, выбор перевода и диапазона глав.
- Последовательная очередь загрузок с отменой текущего и удалением ожидающего задания.
- Постоянный кеш, общая папка сохранения и системная Downloads по умолчанию.
- История с поиском, открытием файла и папки, удалением записи и повторным скачиванием.
- Авторизация по токену с хранением в системном keyring и отображением username.
- Работа в системном трее, уведомления о завершении и диагностический журнал.
- Готовые сборки Windows EXE, macOS DMG и Linux AppImage в GitHub Releases.
- Информация о версии и ссылка на профиль автора в приложении.

### Исправлено

- Обработка результатов фоновых задач в потоке интерфейса и защита выхода во время фоновых операций.
- Восстановление перевода и диапазона при повторном скачивании из истории.
- Проверка отмены перед загрузкой и между этапами, обновление состояния кнопки отмены.
- Обновление системной темы при изменении темы ОС.
- Включение метаданных версии в PyInstaller и запуск desktop-проверок при подготовке релиза.

### Ограничения

- Windows EXE и macOS DMG не подписаны.
- Трей и уведомления зависят от поддержки рабочим окружением; без трея закрытие окна во время фоновых операций блокируется.
- Очередь ожидающих загрузок не восстанавливается после перезапуска.
- Программные интерфейсы остаются экспериментальными.

## [0.3.0] — 2026-11-01

Выпуск добавляет несколько интерфейсов поверх общего ядра скачивания.

### Добавлено

**Python Library**
- Публичный программный интерфейс `ranobe_downloader`.
- Получение информации о произведении, переводах и списке глав.
- Скачивание EPUB, TXT и HTML без интерактивного ввода.
- Поддержка пользовательских провайдеров и обработка ошибок библиотеки.

**Выбор глав**
- Скачивание произвольного диапазона глав по уникальным ID.
- Поддержка одинаковых номеров глав в разных томах.
- Поддержка дробных номеров глав.
- Выбор начальной и конечной главы в CLI, Python Library, HTTP API и Telegram.
- Сохранена совместимость с выбором по номерам глав.

**HTTP API**
- REST API на FastAPI с документацией Swagger.
- Получение метаданных произведений, переводов и списка глав.
- Асинхронные задания скачивания с отслеживанием прогресса.
- Очередь заданий с ограничением количества одновременных загрузок.
- Отмена ожидающих и выполняющихся заданий.
- Удаление завершённых заданий и выходных файлов.
- Автоматическая очистка устаревших результатов.

**Telegram-бот**
- Отдельный интерфейс на `python-telegram-bot`.
- Получение информации о произведении по отправленной ссылке.
- Интерактивные кнопки выбора перевода, глав и формата.
- Постраничная навигация по списку глав.
- Возможность скачать всю книгу, первые 10, последние 10 глав или выбранный диапазон.
- Отправка готовых файлов непосредственно в Telegram.
- Проверка размера файлов перед отправкой.

**Web UI**
- Веб-интерфейс на Vue 3, TypeScript и Vite.
- Адаптивный дизайн для компьютеров и мобильных устройств.
- Поиск произведения по ссылке.
- Выбор переводчика, диапазона глав и формата.
- Отслеживание статуса и прогресса загрузок.
- Управление очередью, отмена и удаление заданий.
- Скачивание готовых файлов через браузер.

**Документация и инфраструктура**
- Обновлён README с инструкциями запуска всех интерфейсов.
- Добавлены `LICENSE`, `CONTRIBUTING.md` и `SECURITY.md`.
- Добавлена документация по Python Library, HTTP API, Telegram и Web UI.
- Добавлена отдельная проверка сборки Web UI в GitHub Actions.
- Подготовлена автоматическая сборка Python-пакета и Web UI для GitHub Releases.

### Улучшено

- Логика скачивания отделена от пользовательских интерфейсов.
- Единое ядро повторно используется в CLI, Python Library, HTTP API и Telegram.
- Диапазоны глав выбираются по фактическому порядку чтения независимо от числового значения ID.
- Список глав можно получить без скачивания их содержимого.
- Подготовленные метаданные книги можно повторно использовать при скачивании.
- Улучшено управление временными файлами HTTP API и Telegram-бота.
- Добавлены ограничения на количество одновременных HTTP-заданий и размер очереди.
- Расширены автоматические тесты для выбора глав и управления загрузками.

### Исправлено

- Неоднозначность выбора глав с одинаковыми номерами в разных томах при использовании ID.
- Ошибки выбора диапазона из-за отсутствующих или неоднозначных числовых границ при переходе на выбор по ID.
- Некорректные сообщения Telegram-бота о хранении слишком больших файлов.

### Известные ограничения

- Поддерживается только RanobeLib.
- HTTP API не имеет встроенной аутентификации и требует защиты при публичном развёртывании.
- Состояние HTTP-заданий и Telegram-сессий не сохраняется после перезапуска.
- Отмена выполняющихся загрузок кооперативная и может происходить с задержкой.
- Недоступные платные главы пропускаются, поэтому итоговая книга может быть неполной.
- Web UI пока использует заглушку вместо обложки произведения.
- Telegram ограничивает размер отправляемого файла.
- Python Library и интерфейсы продолжают развиваться; полная обратная совместимость пока не гарантируется.

## [0.2.0a1] — 2026-10-31

Предварительный выпуск с расширенными форматами экспорта и переработанным ядром.

### Добавлено
- Экспорт книг в EPUB 3, TXT и отдельный HTML-файл (опция `--format`).
- Проверка совместимости произведений через `ranobe audit`, включая выборочную и полную проверку.
- Отчёты аудита в JSON и продолжение проверки с `--resume`.
- Автоматический пропуск недоступных платных глав с отчётом после выгрузки.
- Выбор переводческой ветки и имена выходных файлов вида `<slug_url>_<branch>.<format>`.
- Интеграционные тесты создаваемых EPUB.

### Улучшено
- Разделены загрузка глав, обработка содержимого и экспорт.
- Добавлены контракты провайдеров и возможность внедрять собственные источники данных.
- Единая модель `NormalizedChapter` для экспортёров.
- Кеш глав и изображений, повторные запросы с учётом HTTP 429, обработка HTML и ProseMirror.

### Известные ограничения
- Ядро пока содержит RanobeLib-специфичную загрузку обложек и иллюстраций.
- Экспорт TXT не встраивает изображения, но текущий конвейер может скачивать их.
- Недоступные платные главы пропускаются, и итоговый файл может быть неполным.
- API библиотеки и CLI ещё не объявлены стабильными.
