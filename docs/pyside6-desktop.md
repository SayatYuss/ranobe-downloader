# Приложение PySide6

Актуальная инструкция находится в [руководстве настольного приложения](desktop.md): готовые сборки, запуск из исходников, загрузка книг, очередь, история, настройки и трей.

Для проверки сборок до выпуска откройте GitHub Actions → **PySide6 desktop** → успешный запуск нужного PR/ветки → **Artifacts**. Архивы называются `pyside6-windows`, `pyside6-macos` и `pyside6-linux`; внутри находятся файлы приложения. Проверяйте коммит запуска, чтобы не скачать старую сборку.
