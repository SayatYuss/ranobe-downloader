# Руководства Ranobe Downloader

Если вы впервые открыли репозиторий, начните с [описания проекта](../README.md). Чтобы просто скачать книгу, достаточно готового приложения — установка среды разработки не нужна.

## Для пользователей

1. [Настольное приложение](desktop.md): установка, первая книга, очередь, история и настройки.
2. [Установка из исходников](installation.md): окружение Python и дополнительные зависимости.
3. [Авторизация](authentication.md): где используется токен и как он хранится.
4. [CLI](cli-chapter-range.md): первая загрузка и параметры команд.
5. [Выбор глав](chapter-id-selection.md): переводы, номера, ID и границы диапазона.
6. [Частые проблемы](troubleshooting.md): запуск, доступ к книге и диагностика.

[Google Colab](google-colab.md): скачать книгу с телефона без локальной установки и собственного сервера.
