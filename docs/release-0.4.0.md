# Выпуск 0.4.0: справка

Версия 0.4.0 добавила приложение PySide6 с очередью, историей, кешем, авторизацией и сборками трёх ОС. Изменения перечислены в [CHANGELOG](../CHANGELOG.md).

[Руководство приложения](desktop.md) описывает установку и использование. Для следующих версий используйте [процесс релиза](releasing.md). Старый тег `v0.4.0` повторно создавать или перемещать не следует.
