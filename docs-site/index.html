Ranobe Downloader is a tool for downloading novels from RanobeLib and saving them as files for reading on your own device.

Download app ↗Launch in Colab ↗View source code

What is it?

The downloader takes chapters available on RanobeLib and combines them into a book. You can save a complete novel or select only the chapters you need. It is useful for offline reading, keeping a personal copy, or transferring a book to an e-reader.

Use it only for content you have permission to save and respect the source site's rules.

How to use

  1. 01

    Choose an interface

    Install the desktop app or use the command line. Links to setup instructions are in the repository.

  2. 02

    Provide a RanobeLib link

    Copy the novel URL and paste it into the app or pass it to the CLI command.

  3. 03

    Select chapters and format

    Choose all chapters or a range, select an export format, and start downloading.

  4. 04

    Read offline

    Open the resulting file in your reading app or transfer it to your e-reader.

Export formats

EPUB

Best for e-readers and reading apps. Supports a table of contents and images.

TXT

Plain text, lightweight and easy to process.

HTML

Read in a web browser, with optional images.
