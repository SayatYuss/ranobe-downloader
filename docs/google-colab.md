# Google Colab: загрузка с телефона

[Все руководства](README.md)

[Открыть notebook](https://colab.research.google.com/github/SayatYuss/ranobe-downloader/blob/develop/notebooks/ranobe_downloader_colab.ipynb)

Код выполняется в вашей среде Google Colab; владельцу проекта не нужно запускать сервер. На телефон скачивается готовый файл, Python на телефоне не требуется. Обычно нужен Google-аккаунт. Выберите CPU: ускоритель GPU не используется.

1. Подключите среду кнопкой Connect и запустите шаг 1. Notebook устанавливает актуальную опубликованную версию пакета `ranobe-downloader[images]` из PyPI. Исходники GitHub и wheel вручную не нужны.
2. В шаге 2 вставьте HTTPS-ссылку RanobeLib. Для входа включите authorized: токен вводится отдельно скрытым вводом.
3. Выберите номер перевода из показанного списка и выполните шаг 3. Включите show_all_chapters для полного списка.
4. В шаге 4 выберите EPUB/TXT/HTML и режим глав. Для «Диапазон» используются **позиции в списке от 1**, не ID и не номер главы. Конец 0 означает последнюю главу. Notebook сам преобразует позиции в ID.
5. После успешной сборки запустите шаг 5 и сохраните файл через браузер.

Первый режим по умолчанию — первые 10 глав для проверки. Для новой книги повторяйте шаги 2–5; для другого перевода — 3–5. Не запускайте все ячейки до заполнения полей.

Если notebook не открывается по ссылке, скачайте [notebook](../notebooks/ranobe_downloader_colab.ipynb) из GitHub и загрузите его через File → Upload notebook. Для установки нужен доступ Colab к PyPI; GitHub-токен и ручная загрузка wheel не требуются.

Если передача файла браузером не началась, используйте Files → ranobe-downloads → меню файла → Download либо повторите шаг 5.

## Ограничения

Среда и кеш временные: отключение или удаление среды может потерять результат. Скачайте книгу заранее. Повтор шага 4 в той же среде использует кеш. Не закрывайте среду во время загрузки.

Недоступные платные главы пропускаются; итог может быть неполным. Доступ к RanobeLib из сети Colab не гарантирован. При сетевой ошибке проверьте доступность сайта и параметры; изменения сайта могут потребовать обновления notebook.

Не вписывайте токены в код или Markdown. Скрытый ввод не печатает токен, но он остаётся в памяти среды. Перед передачей notebook очистите вывод с названиями книг и удалите среду, когда закончите.
