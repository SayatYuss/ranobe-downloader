# Contributing

Спасибо за интерес к Ranobe Downloader!

## Перед изменениями

1. Проверь существующие issues и открытые PR, чтобы не дублировать работу.
2. Для нового функционала опиши ожидаемое поведение и ограничения.
3. Создавай отдельную feature-ветку от актуального `develop`; не коммить в `main` напрямую.
4. Не включай в коммиты токены RanobeLib/Telegram, приватные ссылки, скачанные книги, кеши и персональные данные.

## Локальная проверка

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[http,telegram,images]'
python -m unittest discover -s tests -v
cd web
npm install
npm run build
```

Для bug fix добавляй тест воспроизведения. Тесты должны быть детерминированными и по возможности не обращаться к реальному RanobeLib/Telegram API. Для нового провайдера держи его логику в `providers/`; ядро и интерфейсы не должны зависеть от специфики провайдера.

## Pull requests

Кратко опиши проблему, решение, тесты и возможные несовместимые изменения. Один PR — одна связанная задача. Слияние выполняет владелец репозитория после проверки.

## Лицензирование вкладов

Отправляя изменения в проект, ты подтверждаешь, что имеешь право предоставить их под условиями лицензии проекта [MIT](LICENSE). Не включай чужой код и материалы без соответствующих прав.
