# Частые проблемы

[Все руководства](README.md)

| Проблема | Что проверить |
| --- | --- |
| `ranobe: command not found` | Активировано ли окружение и установлен ли пакет в него |
| Нет модуля PySide6, fastapi или telegram | Установлено ли дополнение из [инструкции](installation.md) |
| AppImage требует FUSE | Используйте `--appimage-extract-and-run` из [Desktop](desktop.md) |
| macOS сообщает о неподходящей архитектуре | Готовая сборка текущего workflow — arm64; для Intel нужна совместимая сборка/исходники |
| Linux: Qt не загружает плагин | Проверьте недостающие библиотеки в выводе; для xcb на Ubuntu может требоваться `libxcb-cursor0` |
| Токен не сохраняется | Доступно ли и разблокировано ли системное хранилище keyring |
| Книга не находится | Правильная ли ссылка, доступен ли сайт и разрешён ли доступ аккаунту |
| В книге нет части глав | Правильны ли перевод и диапазон; недоступные платные главы пропускаются |
| Диапазон отклонён | Границы есть в переводе; для повторяющихся номеров используйте ID |
| Загрузка идёт после закрытия окна | При наличии трея это штатно; выход — через его меню |
| В GNOME нет значка | Поддержка трея зависит от окружения и расширений |
| Web UI показывает сетевую ошибку | Запущены ли FastAPI на порту 8000 и Vite |
| HTTP API возвращает 429 | Достигнут лимит очереди или числа заданий |
| Кнопки Telegram устарели | Отправьте ссылку повторно |
| Telegram не отправляет книгу | Предел программы — 45 МиБ; уменьшите диапазон |

## Повтор и диагностика

В CLI `--resume` с прежним `--cache-dir` повторно использует проверенные данные. В Desktop кеш постоянный. Это не восстановление очереди после перезапуска.

Для issue укажите версию, ОС, способ запуска, шаги и ожидаемый/фактический результат. В Desktop журнал открывается через **Настройки → Открыть журнал**.

Удалите из логов и скриншотов секреты и персональные данные. Уязвимости описаны отдельно в [политике безопасности](../SECURITY.md).
