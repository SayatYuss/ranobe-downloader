# Настольное приложение

## Готовые сборки

Скачайте приложение из GitHub Releases. Python и Node.js не требуются.

- Windows x64: запустите EXE.
- macOS: откройте DMG и перенесите приложение в Applications. Архитектура сборки определяется runner macos-15; это не universal binary.
- Linux x86_64: выполните `chmod +x RanobeDownloader-Linux-x86_64.AppImage`, затем запустите файл. Если FUSE недоступен, используйте `./RanobeDownloader-Linux-x86_64.AppImage --appimage-extract-and-run`.

Сборки Windows и macOS не подписаны, поэтому ОС может показать предупреждение.

## Из исходников

```bash
python -m pip install -e '.[desktop,images]'
ranobe-desktop
```

## Использование

Вставьте или перетащите HTTPS-ссылку на RanobeLib, нажмите «Найти», выберите перевод, главы и формат. Кнопка «В очередь» запускает последовательное скачивание. В очереди можно отменить текущую загрузку или удалить ожидающую. Отмена кооперативная: уже выполняющийся сетевой запрос может завершиться позднее.

В настройках задаются общая папка загрузок (по умолчанию системная Downloads), тема и токен. Токен сохраняется через системный keyring; для его хранения нужен доступный backend ОС. После проверки справа сверху отображается username.

Кеш, настройки и история хранятся в пользовательском каталоге приложения через Qt QStandardPaths. Очистка кеша доступна после завершения очереди. История позволяет открыть файл или его папку, удалить запись и повторить скачивание. Удаление записи не удаляет книгу.

При наличии системного трея закрытие окна скрывает приложение, загрузки продолжаются. Для выхода используйте меню трея после завершения фоновых операций. При отсутствии трея закрытие во время фоновых операций блокируется. Уведомления зависят от поддержки ОС и рабочего окружения, включая расширения трея в GNOME.

Диагностический файл `desktop.log` открывается из настроек. Очередь не сохраняется после перезапуска; кеш и история сохраняются.
