# Настольное приложение

[Все руководства](README.md)

Приложение на PySide6 работает в отдельном окне, без браузера и локального HTTP-сервера.

## Скачать и запустить

Откройте [GitHub Releases](https://github.com/SayatYuss/ranobe-downloader/releases), выберите выпуск и раскройте **Assets**.

| ОС | Файл и запуск |
| --- | --- |
| Windows x64 | Скачайте `RanobeDownloader-Windows-x64.exe` и запустите |
| macOS | Откройте `RanobeDownloader-macOS.dmg`, перенесите приложение в Applications |
| Linux x86_64 | Скачайте `RanobeDownloader-Linux-x86_64.AppImage` и разрешите выполнение |

macOS-сборка текущего workflow предназначена для Apple Silicon (arm64); она не является универсальной сборкой для Intel и Apple Silicon. Windows и macOS могут предупреждать об отсутствии подписи издателя.

Linux, из каталога со скачанным файлом:

```bash
chmod +x RanobeDownloader-Linux-x86_64.AppImage
./RanobeDownloader-Linux-x86_64.AppImage
```

Если отсутствует FUSE:

```bash
./RanobeDownloader-Linux-x86_64.AppImage --appimage-extract-and-run
```

Python и Node.js для этих файлов не нужны. Для запуска из исходников выполните [установку](installation.md) с дополнениями `desktop,images`, затем `ranobe-desktop`.

## Скачать первую книгу

1. Скопируйте HTTPS-ссылку со страницы произведения RanobeLib.
2. Вставьте её на вкладке **Скачать** или перетащите в окно.
3. Нажмите **Найти** и дождитесь названия, обложки (если доступна) и списка переводов.
4. Выберите перевод и главы: все, первые 10, последние 10 или диапазон.
5. Выберите EPUB, TXT или HTML и нажмите **В очередь**.
6. Дождитесь завершения. На вкладке **История** выберите запись и нажмите **Открыть файл**.

По умолчанию книги сохраняются в системную папку Downloads. Изменить её можно в **Настройки → Папка загрузок**.

## Очередь и история

Задания выполняются последовательно. **Удалить из очереди** убирает выбранное ожидающее задание; **Отменить текущую** запрашивает отмену активного. Выполняющийся сетевой запрос может завершиться до отмены.

История содержит название, формат, дату и размер. Доступны поиск, открытие файла/папки, удаление записи и повтор. Удаление записи **не удаляет книгу**. Если файл перемещён или удалён вручную, открыть его по старому пути нельзя. У старых записей может отсутствовать информация для повтора.

## Настройки и авторизация

Можно выбрать системную, светлую или тёмную тему, папку загрузок и очистить кеш. Для входа вставьте токен собственной учётной записи и нажмите **Войти**. После проверки справа сверху появится username. Токен сохраняется в системном хранилище учётных данных — [подробнее](authentication.md).

Настройки, история, кеш и `desktop.log` находятся в пользовательском каталоге данных приложения, который выбирает ОС через Qt QStandardPaths. Кнопка **Открыть журнал** находится в настройках. Кеш очищается только после завершения очереди.

## Закрытие окна

Если системный трей доступен, закрытие окна скрывает приложение: загрузки продолжаются. Откройте его через значок трея; для завершения процесса используйте **Выход** после окончания фоновых операций.

Если трей недоступен, закрытие окна завершает приложение только при отсутствии фоновых операций. В GNOME/Wayland поддержка трея зависит от окружения и расширений. Уведомления также зависят от ОС.

После перезапуска сохраняются история, настройки и кеш, но **очередь заданий не восстанавливается**. Возможные проблемы описаны в [диагностике](troubleshooting.md).
